# CodeAlpha_LanguageTranslator
# 🌐 Language Translator App

A simple and interactive web application that translates text between multiple languages using the **Microsoft Translator API**.  
Built with **HTML, CSS, and JavaScript**, this project demonstrates API integration, UI design, and usability features like copy and text‑to‑speech.

---

## ✨ Features
- 🔤 Translate text between English, Hindi, Telugu, French (extendable to more languages).
- 🎛️ User‑friendly interface with source & target language selectors.
- 📋 Copy translated text to clipboard.
- 🔊 Text‑to‑speech functionality for translated output.
- ⚡ Fast and lightweight — runs directly in the browser.
